LAST STATION

This game uses JavaScript modules, so it must be served over http (double-clicking index.html will not load it).

Option 1 (Python installed):  open a terminal in this folder and run:  python -m http.server 8000   then open http://localhost:8000
Option 2 (Node installed):    npx serve .
Option 3: VS Code "Live Server" extension -> Open with Live Server.

The online record sync needs the hosted version; offline the record is saved in the browser.
